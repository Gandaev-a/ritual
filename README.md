# Гранит и благоустройство

Одностраничный сайт для оптовой продажи гранитных комплектов: каталог из прайса
и конфигуратор, который показывает памятник вместе с оградой, покрытием и размером участка.

**Сайт:** https://gandaev-a.github.io/ritual/

**Копия в Claude:** https://claude.ai/code/artifact/7ef3dcde-10e1-43a4-8726-2ab096d51b59

## Сборка

```bash
python3 tools/build.py          # src/* -> index.html + artifact.html
```

`index.html` — полный документ для GitHub Pages: с `charset`, `viewport` и описанием.
`artifact.html` — тот же контент без обёртки, для публикации артефактом (скелет
страницы там добавляется на стороне сервиса). Без `viewport` телефон рендерит
страницу в виртуальном окне 980 px и медиазапросы не срабатывают.

Обновить данные из нового PDF:

```bash
pip install pdfplumber pypdfium2 Pillow numpy scipy
python3 tools/extract_price.py price/opt-price.pdf   # -> models.json + cut/
python3 tools/clean_images.py                        # -> clean/
python3 tools/build.py
```

## Как устроен конфигуратор

**Раньше** конфигуратор пытался составить одну «псевдо-3D» сцену из фотографий
памятника, ограды и мебели — каждая снята своей камерой, под своим углом.
Замер по пикселям базовой линии показал разброс углов: памятники (единый
рендер-риг прайса) 1,3–4,5°, ограды (сканы разных страниц каталога) −3,8…+0,3°,
лавки (отдельные предметные фото) от −22,3° до +8,3°. Никакая перестановка
координат этого не убирает — угол зашит в самом фото. Отсюда были «неровно
стоящий» памятник и лавка, налезающая на цветник.

Дальше было два промежуточных варианта — план участка сверху и предметы в ряд
на общей полосе. Партнёрам оба не понравились: не видно, как выглядит участок.

**Сейчас** снова сцена участка в перспективе (`buildScene` в `src/app.js`), но
**без ограждений** — именно они давали самое заметное расхождение с памятником.
Ограждения остались в каталоге.

- **Плита** на весь участок (2,5 × 2, 2,5 × 3 или 2,5 × 2,5 м) с толщиной 60 мм,
  на ней основание под комплект и сам памятник с цветником.
- **Вазы** стоят по обе стороны от стелы. Их не ставят по формуле от размеров
  прайса: у части моделей цветник на фото шире или снят под другим углом, и вазы
  заходили на его углы. Поэтому для каждого рендера заранее посчитан контур —
  крайние непрозрачные пиксели по полосам 6 px (`tools/spans.py`, поля `sb` и
  `span` в `src/data.json`). Ваза отодвигается от оси могилы шагами по 25 мм,
  пока не встанет целиком за этим контуром.
- **Лавка или стол** — сбоку от могилы. Позиция перебирается, пока габарит
  предмета не перестанет пересекаться с памятником, основанием и вазами;
  сначала ищется место, где низ предмета целиком на плите.
- **Масштаб** малых форм — по реальной опорной величине из каталога (`REAL`):
  лавка по длине 100 см, стол по ширине столешницы 60 см, ваза по высоте 45 см.
  Позиция считается от bbox непрозрачных пикселей (`bx/by/bw/bh`), а не от края
  картинки, поэтому предметы стоят низом на плите.

Проверено перебором всех сочетаний в браузере: 34 памятника × 14 ваз — ни одного
пикселя, где ваза и памятник перекрываются; 34 × 3 участка × 20 лавок и столов —
лавка всегда находит место в пределах участка и не касается памятника. На
участке 2,5 × 2 м лавка длиной 1 м рядом с могилой целиком на плиту не
помещается и встаёт у края (так в 65 % сочетаний).

## Цены

Цены взяты из прайса «Оптовые цены» — за гранитный комплект целиком
(стела + тумба + цветник). Ограждения, керамогранит, газон, основание и установка
в прайс не входят и в конфигураторе показаны без стоимости, только для внешнего вида.

## Публикация

Сайт публикуется на GitHub Pages через `.github/workflows/pages.yml`: workflow
собирает `index.html` из `src/` и выкладывает **только его** — прайс (`price/`)
и исходники по адресу сайта недоступны.

Pages включён (Settings → Pages → Source: GitHub Actions). Каждый push в
`claude/vibrant-allen-dora5i` обновляет сайт автоматически, вручную запускать
ничего не нужно. Ручной запуск при необходимости: вкладка Actions →
«Публикация сайта на GitHub Pages» → Run workflow.

Сайт открыт всем, у кого есть ссылка, — оптовые цены на странице видны.

### Альтернативы

- **Cloudflare Pages / Netlify** — бесплатный тариф, работают с приватным репозиторием,
  дают публичную ссылку. Настройка: подключить репозиторий, команда сборки
  `python3 tools/build.py`, каталог публикации — корень, файл `index.html`.
- **Просто файл.** `index.html` самодостаточен: изображения встроены в него,
  сервер не нужен. Файл можно отправить партнёру — он откроется двойным кликом.
  Шрифты тоже встроены, поэтому страница ничего не загружает из интернета.
  Раньше шрифты брались с fonts.googleapis.com, и если этот адрес не отвечал,
  браузер держал страницу белой, пока ждал таблицу стилей.

## Конфигуратор

- **Участок** — 2,5 × 2 м, 2,5 × 3 м, воинский сектор 2,5 × 2,5 м
- **Изображения** — все рендеры нормализованы: общий масштаб 0,40 px/мм и общая
  базовая линия, поэтому в каталоге и в сцене они стоят ровно, без «прыжков»
- **Малые формы** — лавки, столы и вазы из каталога 2025 (44 позиции)
- **Плита** — гранит серый, тёмно-серый, светло-чёрный, чёрный, белый;
  керамогранит, тротуарная плитка, газон, крошка
- **Малые формы** — скамейка со столом и вазы, цвет гранита выбирается отдельно
- **Форма стелы** — фигурные (24) и прямые (9); разделение считается по силуэту
  рендера: разброс ширины стелы ниже арки, порог 0.015 (`tools/`)

Ограждения в конфигураторе не показываются — 36 моделей с покрытиями в пяти
цветах есть в разделе каталога «Ограждения».
